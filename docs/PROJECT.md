# Project Overview: Vietnam Personal Investment Assistant

## 1. Purpose
A web application designed for learning full-stack/vibe coding while serving as a practical, real-life tool for analyzing investment opportunities in Vietnam.

## 2. Target User
- Single user — personal use only.

## 3. Supported Asset Classes
- Vietnamese stocks
- ETFs / funds
- Gold
- Bank deposits
- Bonds

## 4. Core Product Goals
- Ingest real Vietnamese market data across supported asset classes.
- Receive stock prices in realtime where supported.
- Detect new financial/news information around every 30–60 seconds.
- Analyze important news promptly with AI.
- Analyze market conditions.
- Analyze and rank candidate investment opportunities.
- Explain evidence, risks, and uncertainty clearly.
- Personalize analysis based on user profile.

## 5. Non-Goals
- Does NOT execute trades.
- Does NOT connect to a broker for buy/sell orders.
- Does NOT automatically invest money.

## 6. Personalization Goals
Tailor opportunity analysis and ranking based on:
- Available capital
- Risk tolerance
- Investment horizon
- Current portfolio

## 7. Analysis & AI Principles
- Quantitative scores must come from data, rules, or models.
- LLM must NOT invent financial scores from intuition alone.
- AI should primarily interpret, summarize, and explain evidence.

## 8. Learning Objective
- Learning full-stack and vibe coding while building a practically usable tool.
